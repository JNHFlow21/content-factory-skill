# dbs 五维诊断 prompt 模板

> 用于 Step 4.5，对文章初稿进行五维爆款特质诊断

---

## 诊断框架

| 维度 | 满分 | 检查内容 |
|------|------|---------|
| 文字洁癖 | 20分 | 有没有AI味、套话、术语不解释、居高临下 |
| 封面/标题 | 20分 | 平铺直叙能不能吸引人、标题是否有钩子 |
| 表达效率 | 20分 | 一句话能否说清核心观点、段落是否冗余 |
| 认知落差 | 20分 | 受众看完会不会觉得"我早知道了" |
| AI辅助 | 20分 | 配合工作流推荐、有没有具体操作指引 |

**及格线**：各维度 ≥80%（16分）
**危险线**：核心维度（文字洁癖/认知落差）<60%（12分）

---

## 诊断 prompt

```
你是一个爆款内容诊断师。请对以下公众号文章进行五维诊断。

## 文章内容
{ARTICLE_CONTENT}

## 诊断框架（百分制）

| 维度 | 满分 | 得分 | 具体问题 |
|------|------|------|---------|
| 文字洁癖 | 20 | ? | |
| 封面/标题 | 20 | ? | |
| 表达效率 | 20 | ? | |
| 认知落差 | 20 | ? | |
| AI辅助 | 20 | ? | |

## 诊断标准

**文字洁癖（20分）**
- 扣分项：AI常用套话（"值得注意的是"、"毋庸置疑"）、术语不解释、居高临下（"你必须"、"你肯定不知道"）、强行励志
- 加分项：大白话、有温度、像朋友说话

**封面/标题（20分）**
- 扣分项：平铺直叙、没有数字/效果承诺/反差感
- 加分项：标题有钩子、能引发好奇或共鸣

**表达效率（20分）**
- 扣分项：一段话说不清核心观点、段落冗余（超过5句没分段落）、废话多
- 加分项：一句话能概括核心、段落清晰

**认知落差（20分）**
- 扣分项：受众看完觉得"我早知道了"、没有新认知冲击
- 加分项：反常识/颠覆认知、有独特见解

**AI辅助（20分）**
- 扣分项：只有理论没有操作指引、AI工具没说具体名字
- 加分项：有具体工具名、有操作步骤、有案例

## 输出格式

**总分**：/100

**各维度详细点评**：
- 文字洁癖：{得分}/20 — {具体问题}
- 封面/标题：{得分}/20 — {具体问题}
- 表达效率：{得分}/20 — {具体问题}
- 认知落差：{得分}/20 — {具体问题}
- AI辅助：{得分}/20 — {具体问题}

**核心问题**（如果有维度<12分）：
{列出需要修改的具体句子或段落}

**修改建议**：
{针对每个问题给出具体修改方向}

**结论**：
- ✅ 全通过（≥80）→ 可进入下一步
- ⚠️ 需打磨（各维度≥12但有<16）→ 自动修改后重新诊断
- ❌ 需重写（文字洁癖或认知落差<12）→ 建议用户重写
```

---

## 打磨循环规则

1. **初稿诊断** → 给出修改建议
2. **自动修改** → 按建议改稿
3. **重新诊断** → 验证修改效果
4. **最多5轮循环**
5. 用户可随时说「跳过诊断直接发布」终止循环

---

## 适用场景

- Step 4.5：文章初稿完成后、五维诊断打磨
- Flow 2深化选题后：脚本草稿的简易诊断（可简化为3维度）
- 用户说「帮我看看这个文案」时：快速诊断
